关于本项目

项目背景

本项目是一个基于 Flask 框架的人像卡通化 Web 应用，采用 MVC 架构模式组织代码。 通过集成 ModelScope 平台的 DCT-Net 预训练模型，实现了用户上传照片后自动生成卡通风格图片的功能。

项目旨在展示如何将深度学习模型（DCT-Net）与传统 Web 框架（Flask）结合， 为用户提供便捷的人像卡通化服务。

使用步骤
  1. 注册账号 — 点击导航栏「注册」，输入用户名和密码完成注册
  2. 登录系统 — 使用注册的账号登录
  3. 上传图片 — 点击「卡通化」，选择一张人像照片上传
  4. 查看结果 — 系统自动处理后展示原图与卡通化结果对比
  5. 下载保存 — 点击「下载结果」保存卡通化图片
开发环境
  • 操作系统: Windows 10/11
  • Python 版本: >= 3.10
  • Web 框架: Flask 3.0+
  • 数据库: SQLite（开发环境）

安装命令: pip install -r requirements.txt

模型来源

卡通化模型采用 DCT-Net（Disentangled Cartoonization Transformer）， 来自阿里巴巴达摩院（DAMO Academy）在 ModelScope 平台发布的预训练模型。

  • 模型 ID: damo/cv_unet_person-image-cartoon_compound-models
  • 模型名称: DCT-Net 人像卡通化模型
  • 来源平台: ModelScope（阿里云 AI 模型平台）
  • 首次加载: 启动时自动下载，约需几百 MB 磁盘空间
