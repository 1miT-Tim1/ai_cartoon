关于本项目

项目背景

本项目是一个基于 Flask 框架的人像卡通化 Web 应用，采用 MVC 架构模式组织代码。 通过集成 ModelScope 平台的多款预训练模型，实现了用户上传照片后自动生成多种风格卡通图片的功能。

项目支持动漫、3D、手绘、素描四种风格切换，每个模型独立惰性加载，为用户提供便捷的人像卡通化服务。

使用步骤
  1. 注册账号 — 点击导航栏「注册」，输入用户名和密码完成注册
  2. 登录系统 — 使用注册的账号登录
  3. 选择风格 — 在「卡通化」页面选择喜欢的风格（动漫/3D/手绘/素描）
  4. 上传图片 — 拖拽或选择一张人像照片上传
  5. 查看结果 — 系统自动处理后展示原图与卡通化结果对比
  6. 下载保存 — 点击「下载结果」保存卡通化图片
开发环境
  • 操作系统: Windows 10/11
  • Python 版本: >= 3.10
  • Web 框架: Flask 3.0+
  • 数据库: SQLite（开发环境）

模型来源

所有卡通化模型均来自阿里巴巴达摩院（DAMO Academy）在 ModelScope 平台发布的预训练模型， 基于 DCT-Net（Disentangled Cartoonization Transformer）架构。

动漫风格damo/cv_unet_person-image-cartoon_compound-models
3D风格damo/cv_unet_person-image-cartoon-3d_compound-models
手绘风格damo/cv_unet_person-image-cartoon-handdrawn_compound-models
素描风格damo/cv_unet_person-image-cartoon-sketch_compound-models

首次使用某模型时会自动下载，每个模型约需几百 MB 磁盘空间。模型采用惰性加载策略，按需加载。
